# Onzaris

**Supervised, exception-driven soccer operations.**

Onzaris is a bilingual operations concept for leagues, tournaments, clubs and independent soccer competitions. It connects scheduling, fields, officials, game sheets, results and communications so routine work can move through one workflow while sensitive decisions remain with the responsible person.

## Why it exists

Small and mid-sized sports organizations often move the same information between spreadsheets, email, messaging apps and an official federation system. The first Onzaris use case is deliberately narrow: run one real competition in parallel, measure the removed administrative work, and preserve a complete export and rollback path.

## Product direction

- conflict-aware scheduling and rescheduling;
- official availability, eligibility and assignment workflow;
- role-specific game-day and result workflows;
- targeted communications connected to operational changes;
- bilingual, responsive experiences for administrators, officials, members and teams;
- controlled AI recommendations with human approval and an audit trail.

## What this public repository contains

This repository is a **portfolio-facing project brief**, not the production source code. The implementation repository, operational data, credentials, CRM exports, test fixtures and deployment configuration are intentionally kept private.

The live product site is available at [www.onzaris.com](https://www.onzaris.com).

## Current validation stage

Onzaris is being validated through a paid, assisted pilot for one bounded competition. The key question is not whether AI can generate a schedule; it is whether an organization can remove manual work without creating another layer of duplicate entry beside its mandated system.

The next evidence target is a small cohort of real organizations willing to share a workflow, provide a non-sensitive export and test a parallel operating loop with measurable success criteria.
